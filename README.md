# BIUSTAZ — GitHub Pages нұсқасы

Бұл сайт GitHub Pages-ке жүктеуге дайын. Ол бір HTML файлын емес, шағын әрі жүйелі файл құрылымын қолданады.

## Файл құрылымы

```text
BIUSTAZ_GitHub_Pages/
├─ index.html          # басты сайт, GitHub Pages осыны ашады
├─ style.css           # дизайн
├─ app.js              # 11 модуль логикасы
├─ .nojekyll           # GitHub Pages-ке арналған файл
├─ audio/
│  ├─ ertegi_01.mp3
│  ├─ ertegi_02.mp3
│  ├─ ertegi_03.mp3
│  ├─ ertegi_kustar.mp3
│  ├─ ertegi_zhaksylyk.mp3
│  └─ manifest.json
└─ assets/images/
   └─ 8 иллюстрация (.webp)
```

## GitHub-қа жүктеу (сайттан)

1. Осы ZIP архивті Windows-та шығарыңыз (*Extract All*).
2. github.com сайтына кіріп, **New repository** басыңыз. Атауы, мысалы `biustaz`.
3. Repository ішінде **Add file → Upload files** батырмасын басыңыз.
4. ZIP файлын емес, ашылған `BIUSTAZ_GitHub_Pages` папкасының **ішіндегі барлық файлдар мен қалталарды** жүктеңіз.
5. Тексеріңіз: `index.html`, `app.js`, `style.css`, `audio/`, `assets/images/` репозиторийдің **негізінде** болуы керек.
6. **Commit changes** басыңыз.
7. **Settings → Pages → Build and deployment → Deploy from a branch** таңдаңыз.
8. Branch: `main`, folder: `/(root)`, Save. Сайттың сілтемесі сол бетте пайда болады. Жариялануына бірнеше минут кетуі мүмкін.

Мысал мекенжай: `https://USERNAME.github.io/biustaz/` (өзіңіздің GitHub логиніңізді және repository атауын қолданыңыз).

## Ертегі аудиолары сақтала ма?

Иә. Бес аудио **`audio/` папкасында** бірге жүктеледі. Олар Google Drive сілтемесімен емес, `audio/ertegi_01.mp3` сияқты салыстырмалы жолмен ойнатылады. Осылайша GitHub Pages ішінде жұмыс істейді. Файлдарды өшірмеңіз және аттарын өзгертпеңіз.

Жүктеуді жеңілдету үшін MP3-лар 96 kbps форматта қайта кодталған. Бұл нұсқада мазмұн толық сақталды, алайда биттік тұрғыдан бастапқы MP3-мен бірдей емес. **Бастапқы сападағы түпнұсқалар Google Drive-та сақталады:**
https://drive.google.com/drive/folders/1s7kEc8YmdC57lOK3ursPcYFJ2KpXRT3M?usp=drive_link

Аудио атаулары: алғашқы үшеуінде нақты шығарма атауы түпкілікті расталмаған, сондықтан олар интерфейсте «Аудиоертегі №1–3» ретінде көрсетіледі (сайтта уақытша атауды өзгертуге болады).

## Маңызды

Бұл — frontend-ке негізделген прототип. QR арқылы бір мезгілде әр құрылғыдан қатысу, нақты ЖИ API және серверлік деректер қоры GitHub Pages-тің өзінде іске аспайды. Мұғалім басқаратын жергілікті ойындар, дизайн, мазмұн және MP3 ойнатқыштары жұмыс істейді.
